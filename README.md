# Git Workflow Practice

A simple Git and GitHub workflow practice project built for the FlexiSAF Frontend Internship.

## Live Demo

https://abraham3stack.github.io/git-workflow-practice/

## Project Overview

This project demonstrates common Git and GitHub workflow operations including:

- Repository initialization
- Creating branches
- Committing changes
- Renaming branches
- Pushing and pulling changes
- Creating pull requests
- Merging pull requests
- Responsive UI updates

## Features

- Responsive navigation bar
- Responsive layout
- Footer section
- Git workflow documentation
- GitHub Pages deployment

## Git Commands Practiced

```bash
git init
git checkout -b feature/navbar
git checkout -b feature/footer
git branch -m feature/site-footer
git add .
git commit -m "Commit message"
git push -u origin branch-name
git pull
